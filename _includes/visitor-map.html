{% comment %} Visitor world map. Self-contained on purpose: the outline is an inline SVG generated from Natural Earth 110m country polygons in a plain equirectangular projection, so there is no map library and no tile server to fetch. That matters because the readers this map exists to show are the ones behind the Great Firewall, and every third-party map CDN is a coin flip there. Dots come from the worker's public /visits feed (no IP addresses). The projection below must stay in step with the one in the generator: x = (lon + 180) * 2 ; y = (84 - lat) * 2 ; viewBox 0 0 720 284 Antarctica is cropped so the map reads as a banner rather than a square with an empty slab along the bottom. Set SHOW_MAPMYVISITORS to true to bring back the old third-party widget. It is off because it charts its own separately collected numbers rather than this site's, and it never saw a Chinese visitor at all. {% endcomment %}
